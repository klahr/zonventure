Common questions

Why is there no price for the hosted offering?

The platform is open source. Anyone can run a hosted instance and set their own pricing. If you reached this page from a hosted operator, ask them — they're the ones billing you. We don't centralise that.

What does self-hosting actually require?

A small Linux box (any cloud VPS), Postgres, and either an SMTP relay or a willingness to copy magic links from the server log during development. Docker Compose ships in the repo and brings everything up with one command. See the manual for the full setup walk-through.

Can I charge players for an event on a self-hosted instance?

Yes. Wire up your own Stripe credentials and the public store routes (/store, /o/<org>/store) become buyable. Stripe takes its standard processing fee; you keep the rest. Set the team price to 0 under Settings → Pricing and nothing more is taken.

Is my data tied into a specific provider?

No. Everything lives in your Postgres database. There's a built-in org-bundle export you can use to migrate to another instance — same code on both sides, so the bundle is portable.
